Scaling

Cascade uses a shared scale to keep dimensions, spacing, and typography in proportion as the viewport changes.

pxv

Think of pxv as a design-reference pixel. Write the size from your design, and Cascade scales it using the viewport and the active mobile or desktop settings.

.card {
  width: 300pxv;
  padding: 24pxv;
}

The PostCSS plugin converts 24pxv to calc(24 * var(--pxv-unit)). One shared unit keeps every pxv value in proportion. Standard px values stay fixed.

The reference width defaults to 390 on mobile and 1440 on desktop. With width-only scaling, 100pxv equals 100px at the reference width and 80px at 80% of that width, before minimum and maximum limits apply.

Height influence
Squish lets short viewports reduce the width-based scale. At 0, scaling follows width alone; at 1, the full height constraint applies.
Floor
A minimum viewport height for the height calculation, so short windows do not keep shrinking the scale indefinitely.
Maximum width
Caps the scale calculation. It does not change the layout breakpoint.
Reference height
The design height used by the height constraint. It matters when squish is above zero.
When to use pxv

Basically always! Use pxv for sizes that should scale with the composition. Keep fixed pixels where appropriate, such as a 1px border, and use percentages or layout tools for flexible structure. Typography also applies minimum font-size clamps for readability.

Utilities

Only include what you need. In your project's copy of scss/01-base/utilities/_index.scss, comment out unused utilities and rebuild to remove their CSS from the output:

@forward 'dev';
@forward 'display';
@forward 'flex';
@forward 'spacing';
// @forward 'scrim';
// @forward 'shadow';

Attribute selectors keep a utility's options together instead of mixing them into a long class list. For example, shadow="20 .1" controls elevation and intensity, while scrim="to-t .5 75%" groups overlay options. Flex layouts use class utilities such as class="flex j-sb a-c". The attribute-based utilities read whitespace-separated options; flex uses modifier classes. These are ordinary CSS selectors, so no JavaScript is needed.

.flex

Use class="flex" to create a flex container, then add modifier classes such as class="flex j-sb a-c column-mobile wrap".

Justification follows the main axis; alignment follows the cross axis. These axes swap when using a column. Modifiers ending in -mobile apply below the shared tablet breakpoint; -desktop modifiers apply at and above it.

[shadow]

Explore the shadow CodePen

Combine elevation, intensity, and an optional color. Options can appear in any order.

<div shadow="20 .1 blue">A low blue shadow</div>
Elevation
10, 20, 30, 40, or 50, from a tight shadow to a broad, lifted shadow. These are preset names, not pixel measurements.
Intensity
.1 through .9, from lighter to darker. This sets the base opacity; individual shadow layers also apply weights, so it is not the final combined opacity.
Color
black by default. Add blue for the blue preset, or set style="--shadow-color: 120, 40, 90;" for a custom RGB color.
Hover only
use shadow-hover="30 .1". It also activates on keyboard focus for buttons and links.
Resting and hover
combine shadow="20 .1" with shadow-hover="50 .2". Hover settings override only the options supplied; omitted options retain the resting values.

Use shadow for a persistent shadow. Elevation presets run from 10 (tight) to 50 (broad). Bare shadow defaults to elevation 30 with intensity 0.08.

[scrim]

A scrim is a gradient overlay that darkens part of an image and fades to transparent. Use it behind text on photos, hero images, or cards to improve readability while keeping the image visible. Choose a direction that puts the darkest area behind your text, and check contrast against the actual image.

Images & positioning

Image fitting

Give the frame a height or aspect ratio, then choose how the image fills it.

Cover

Fill the frame; crop the edges.

Contain

Show the whole image; leave space as needed.

<figure class="fit-photo cover" style="aspect-ratio: 16 / 9;">
  <img src="photo.jpg" alt="Describe the image">
</figure>

Use .fit-photo.contain instead of .fit-photo.cover to preserve the entire image. Both work with direct child images and videos.

Positioning

.relative
Establishes a positioned parent.
.absolute
Positions an element relative to its positioned ancestor.

Fills a positioned parent with an absolutely positioned element.

Clipping

A decorative layer clipped to its wrapper, with a fixed, viewport-height inner layer.

<div class="clip-container">
  <div class="clip-container__inner">Decorative content</div>
</div>

The wrapper disables pointer events. Keep interactive content outside it.
