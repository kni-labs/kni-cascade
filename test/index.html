Hanging quotes

Opening quotes hang outside the alignment guide. Browsers without native support use the configurable first-line indent.

“Good typography lets the words do the talking. This longer quote wraps onto another line so you can compare the opening punctuation with the text below it.”

Custom offset for a different font:

“Each typeface draws quotation marks differently. Adjust the fallback offset to match the font used by your project.”

Disabled: native hanging set to none, fallback offset set to zero.

“This opening quote stays inside the alignment guide.”

Ordinary text has no fallback indent. Only text marked with the hanging-quote class receives it.

Shadows

Explore the shadow CodePen

Like scrim, shadow accepts space-separated options: elevation, intensity, and optional color. For example, shadow="20 .1 blue" creates a low blue shadow. Options can appear in any order.

  • Elevation: 10, 20, 30, 40, or 50, from a tight shadow to a broad, lifted shadow. These are preset names, not pixel measurements.
  • Intensity: .1 through .9, from lighter to darker. This sets the base opacity; individual shadow layers also apply weights, so it is not the final combined opacity.
  • Color: black by default. Add blue for the blue preset, or set style="--shadow-color: 120, 40, 90;" for a custom RGB color.
  • Hover only: use shadow-hover="30 .1". It also activates on keyboard focus for buttons and links.
  • Resting and hover: combine shadow="20 .1" with shadow-hover="50 .2". Hover settings override only the options supplied; omitted options retain the resting values.

Use shadow for a persistent shadow. Elevation presets run from 10 (tight) to 50 (broad). Bare shadow defaults to elevation 30 with intensity 0.08.
